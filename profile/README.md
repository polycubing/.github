# Polycubing

A machine-verified census of which small polycubes tile space, which provably cannot, and which resist classification.

Every polycube through nine cells, 56,463 shapes, carries a verdict and a certificate anyone can recheck without trusting us. Tilings are rechecked with plain geometry. Refutations are DRAT proofs replayed by an independent checker.

- [census](https://github.com/polycubing/census): the data and the pipeline. Shape ids are paths, so `9/2127` is a permanent name.
- [polycubes.org](https://polycubes.org): the public face.

What the census has settled so far: every polycube with one to seven cells tiles space. The smallest that cannot is the flat 3×3 square ring, eight cells, with Heesch number 1. Through nine cells there are six proven non-tilers and eight shapes that wrap themselves twice but admit no periodic tiling within stated budgets, the first shapes known to do that in three dimensions.
